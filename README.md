# व्यक्तिगत डेटा फॉर्म और डॉक्यूमेंट एक्सपोर्ट (Personal Data Form)

HTML, CSS (Tailwind) और JavaScript से बना एक सिंगल-पेज वेब प्रोजेक्ट, जिसकी मदद से आप अपना व्यक्तिगत डेटा और फोटो भरकर एक क्लिक में **Excel (.xlsx)**, **MS Word (.docx)** और **CSV (.csv)** फाइलें डाउनलोड कर सकते हैं।

## मुख्य विशेषताएँ
- **फोटो अपलोड:** ड्रैग-एंड-ड्रॉप या ब्राउज़ करके JPG/PNG फोटो जोड़ें।
- **Excel (.xlsx) एक्सपोर्ट:** फॉर्मेटेड शीट में आपका डेटा और असली फोटो।
- **MS Word (.docx) एक्सपोर्ट:** प्रोफेशनल प्रोफ़ाइल डॉक्यूमेंट में टेबल और फोटो।
- **CSV (.csv) एक्सपोर्ट:** UTF-8 सपोर्ट के साथ हिंदी और अंग्रेजी डेटा।
- **लाइव प्रीव्यू:** टाइप करते ही नीचे डिजिटल प्रोफ़ाइल कार्ड अपडेट होता है।

## उपयोग कैसे करें
1. `index.html` को किसी भी आधुनिक ब्राउज़र (Chrome, Edge, Firefox) में खोलें।
2. अपना विवरण भरें और फोटो अपलोड करें।
3. अपनी पसंद के अनुसार **Excel**, **MS Word**, **CSV** या **तीनों फाइलें एक साथ डाउनलोड करें** बटन पर क्लिक करें।
